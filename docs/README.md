# Dokumentacja NT1100 Telemetria

Krótko, po polsku, krok po kroku. Szczegóły funkcji dodatku są w `nt1100_jazdy/DOCS.md`
(widać je też w Home Assistant: Dodatki → NT1100 Jazdy → Dokumentacja).

| Plik | Dla kogo | Co w nim jest |
|---|---|---|
| [architektura.md](architektura.md) | każdy | z czego składa się system, kto z kim rozmawia, gdzie leżą dane |
| [instalacja.md](instalacja.md) | właściciel | uruchomienie od zera: dodatek, skrzynka, ekran, silnik tras |
| [problemy.md](problemy.md) | właściciel | co zrobić, gdy coś nie działa (objaw → przyczyna → co zrobić) |
| [wydanie.md](wydanie.md) | osoba, która zmienia kod | jak wydać nową wersję dodatku i oprogramowania urządzeń |
| `../silnik-tras/README.md` | właściciel | kontener z silnikiem tras i mapą |

Zasada, która nie zmienia się nigdy: **aktualizujesz tylko dodatek w Home Assistant**.
Skrzynka i ekran dostają nowe oprogramowanie od dodatku.

W tym repozytorium nie ma (i nie może być): kluczy podpisu oprogramowania, haseł, adresów
domowych, nazw części elektronicznych ani źródeł oprogramowania skrzynki i ekranu.
Repozytorium jest publiczne.
